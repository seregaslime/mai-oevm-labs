## Лабораторная работа №1

Моделирование функционирования АЛУ при выполнении операции сложения/вычитания
над числами с фиксированной точкой. Переполнение разрядной сетки отслеживается
модифицированным кодом: 9-разрядные регистры, из них 2 знаковых разряда и
7 информационных. Если знаковые разряды совпадают — переполнения нет.

Вариант 10:

| Первый операнд | Второй операнд | Операция | Результат |
|---|---|---|---|
| 68 | 17 | + | 85 |
| 25 | 68 | − | −43 |
| 98 | −55 | − | переполнение (153 > 127) |

### Запуск

Дистрибутив MCL в репозиторий не залит (архив на 67 МБ). Программа открывается
через **Файл → Открыть** в `MCL 1.7.exe` после выбора лабораторной работы №1.
Программа запрашивает три значения: операнд `A`, операнд `B` и код операции
`I` (`0` — сложение, `1` — вычитание).

## Лабораторная работа №2 (№4 по методичке)

Моделирование функционирования операционной части центрального процессора.
Двухадресная команда сложения (КОП = 1), формат `KOP[15..14] OP1[13..7] OP2[6..0]`.

Вариант 7: 1-й операнд — **прямая** адресация, 2-й — **косвенно-регистровая**,
результат записывается на место 1-го операнда (в ОП).

Данные, которые нужно задать в интерфейсе MCL (остальное — нули):

| Ячейка | Значение | Смысл |
|---|---|---|
| `ZS[1]` | 17284 (`01 0000111 0000100`) | команда: A1 = 7, A2 = 4 |
| `ZS[7]` | 15 | 1-й операнд |
| `RON[4]` | 10 | адрес 2-го операнда |
| `ZS[10]` | 6 | 2-й операнд |

При запуске в СК вводится `1`. Ожидаемый результат: `ZS[7] = 15 + 6 = 21`, `SK = 2`.

В MCL после **Файл → Открыть** выбрать лабораторную «Операционная часть».

Схемы перегенерируются `python3 ЛР2/отчет/src/схемы.py`, отчёт — `python3 ЛР2/отчет/src/отчет.py`.

## Лабораторная работа №3 (№5 по методичке)

Моделирование горизонтального микропрограммного блока устройства управления.
В MCL выбрать лабораторную «Блок устройства управления»; программа моделирования
встроена в среду, нужно только заполнить управляющую матрицу (адресная часть
заполнена средой: следующая МК = текущая + 1). Данные те же, что в ЛР2
(команда в ячейке 1: КОП 1, ОП1 7, ОП2 4; `ZS[7]=15`, `ZS[10]=6`, `РОН 4 = 10`, СК = 1).

Отметки в матрице (строка сверху вниз → вентили), с совмещением микроопераций:

| МК | Вентили | Микрооперации |
|---|---|---|
| 0 | V1 | `RAP:=SK` |
| 1 | V5 | `RCH:=ZS[RAP]` |
| 2 | V2, V3 | `RK:=RCH; SK:=SK+1` |
| 3 | V7, V9 | `RAP:=RK.OP1; RARP:=RK.OP2` |
| 4 | V5, V11 | `RCH:=ZS[RAP]; RCHR:=RON[RARP]` |
| 5 | V6, V12 | `RA:=RCH; RAP:=RCHR` |
| 6 | V5 | `RCH:=ZS[RAP]` |
| 7 | V8, V7 | `RB:=RCH; RAP:=RK.OP1` |
| 8 | V13 | `RC:=RA+RB` |
| 9 | V14 | `RCH:=RC` |
| 10 | V4 | `ZS[RAP]:=RCH` |

Результат: `ZS[7] = 21`. Схемы — `python3 ЛР3/отчет/src/схемы.py`, отчёт — `python3 ЛР3/отчет/src/отчет.py`.
